# RobloxGang Utilities 1.1.2

- Обводка барьеров больше не видна через непрозрачные блоки: она рисуется в мире с проверкой глубины.
- Если стена закрывает только часть барьера, скрывается только перекрытая часть контура.
- Серый полупрозрачный цвет и переключатель функции сохранены.
- Обновлено настоящее игровое превью: барьеры частично закрыты каменной стеной.

Проверено на локальных vanilla-серверах 1.21.10 и 26.3: открытый барьер, сплошная стена, частичное перекрытие; снимки сравнивались с отключённой обводкой. Сборки подготовлены для всех семи поддерживаемых версий.
