# RobloxGang Utilities 1.0.2

Клиентский мод для Fabric: быстрый выбор режима приседа, напоминание о 52 и цвета участников RobloxGang.

## Возможности

- **G** переключает штатную настройку приседа Hold / Toggle. Результат показывается анимированным уведомлением справа сверху.
- Каждый час в **:52** появляется напоминание с перезвоном и текущим биндом. **H** отправляет `52` в чат.
- Имена пяти участников окрашиваются в табе, чате и неймтэгах. Определение по UUID, с fallback по актуальному нику из Mojang API для offline-серверов.
- В Mod Menu можно выбрать приоритет цвета сервера или клиента; по умолчанию приоритет у сервера.
- В настройках встроены настоящие кадры из мира на локальном тестовом сервере. Таб показывает все пять ников; чат открывается отдельно.

## Установка

Выберите **один JAR с точной версией Minecraft** и поместите его в `mods`. Установите Fabric Loader и Fabric API; для графического меню настроек нужен Mod Menu. Другие библиотеки интерфейса не требуются.

Поддерживаются **1.21.10, 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2 и 26.3**. Для 1.21.x нужна Java 21+, для 26.x — Java 25+. Таблица проверенных зависимостей находится в README.

При обновлении сохранённые назначения клавиш не меняются. Чтобы применить G/H, сбросьте соответствующие действия в настройках управления Minecraft.

## Проверки и ограничения

Локально для каждой из семи сборок прошли девять unit-тестов и запуск клиента. На vanilla-сервере 1.21.10 проверены пять offline-профилей, таб, чат и бинды. В скриншотах использованы автоматизированные тестовые профили, а не реальные владельцы аккаунтов; напоминание вызвано штатным предпросмотром.

Нестандартные форматы серверного чата и неймтэги сторонних плагинов могут потребовать дополнительной адаптации. GitHub CI отдельно проверяет сборку, unit-тесты и состав JAR; графический клиент на CI не запускается.

В релизе должны быть семь JAR и `SHA256SUMS.txt`. Контрольные суммы относятся к приложенным файлам конкретной сборки.
