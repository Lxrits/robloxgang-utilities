# История сборок

## 1.0.2

- Настоящие скриншоты из мира на локальном тестовом сервере вместо нарисованных демонстрационных экранов.
- В превью таба одновременно видны все пять участников RobloxGang.
- Отдельный просмотр чата в галерее окраски; снимки уведомлений на фоне мира.
- Масштабирование галереи под высоту окна.

## 1.0.1

- Клавиши по умолчанию: G — переключение приседа, H — сообщение `52`.
- Выбор приоритета цвета имени: сервер или клиент. По умолчанию — сервер.

## 1.0.0

- Переключение штатного режима приседа Hold / Toggle с уведомлением.
- Ежечасное напоминание в :52 и отдельный бинд отправки `52`.
- Цвета участников по UUID, fallback по актуальному нику из Mojang API, локальный кэш.
- Настройки через Mod Menu, клиентская установка, отдельные JAR для семи версий Minecraft.

Это история подготовленных сборок, а не утверждение о датах их публичной публикации.
