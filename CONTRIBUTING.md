# Разработка

Нужны JDK 25 и PowerShell 7. Gradle Wrapper включён. Не устанавливайте тестовый мод `src/smoke` в обычный экземпляр игры.

```powershell
./build-all.ps1 -MinecraftVersion 1.21.10
./build-all.ps1
```

Для одной версии используется `scripts/build-one.ps1`; матрица зависимостей читается из `versions.json`, версия мода — из `gradle.properties`. Результаты находятся в `dist/<версия-мода>/`. Каждая Minecraft-версия получает отдельный кэш проекта Gradle.

Общий код хранится в `src/main/java`. Адаптация имён API выполняется задачами `adapt12111` и `modernSources`. При изменении кода с переименованием методов проверьте обе ветки сборки и соответствующие пункты матрицы.

CI собирает мод, запускает unit-тесты и проверяет состав JAR. Он не заменяет игровой прогон: изменения HUD, биндов, Mixin или галереи проверяйте в клиенте. Вспомогательный `src/smoke` и инструкции `tools/demo/README.md` предназначены для локальной проверки и не входят в выпускаемые JAR.

В PR укажите поведение до/после изменения, затронутые версии и выполненные проверки. Для изменений интерфейса приложите снимок из клиента.

Перед новым релизом обновите `mod_version`, `CHANGELOG.md`, файл `releases/<версия>.md` и при необходимости `versions.json`. Порядок выпуска описан в [PUBLISH.md](PUBLISH.md).
