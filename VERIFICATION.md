# Проверки RobloxGang Utilities 1.0.2

Дата: 12 ноября 2026 года.

| Minecraft | Сборка и 9 автоматических тестов | Запуск клиента и проверка интерфейса |
|---|---|---|

| 1.21.11 | Пройдено | Пройдено |
| 26.1 | Пройдено | Пройдено |
| 26.1.1 | Пройдено | Пройдено |
| 26.1.2 | Пройдено | Пройдено |
| 26.2 | Пройдено | Пройдено |
| 26.3 | Пройдено | Пройдено |

Автоматические тесты проверяют однократное срабатывание в :52, следующий час, откат времени, повторный час при смене летнего времени, приоритет UUID, актуальный ник вместо устаревших псевдонимов, точное сравнение имён, унаследованный серверный цвет, явно белый цвет, имя из нескольких текстовых компонентов, сохранение префикса/суффикса, отказ от частичного перекрашивания и отключение функции/участника.

Отдельный тестовый мод запускал каждый клиент, проверял реальное включение Toggle-состояния приседа и его сброс, загрузку классов с Mixin-вставками, открытие настроек и отрисовку демонстрационных экранов. Успех отмечен строкой `RG_SMOKE_OK`, после которой клиент штатно завершался. Тестовый мод не включён в релизные JAR.

Вручную через интерфейс проверено открытие настроек из Mod Menu на 1.21.10 и главное меню 26.3. Из клиента 1.21.10, подключённого к локальному vanilla-серверу, получены четыре настоящих кадра мира: таб со всеми пятью участниками, чат и оба уведомления. Использованы автоматизированные тестовые профили. Изображения просмотрены и включены в ресурсы каждой сборки. Реальные запросы к Mojang успешно вернули имена всех пяти UUID и сохранились в кэш.

Релизные архивы дополнительно проверяются на точную зависимость от Minecraft, Java и Fabric Loader, наличие четырёх PNG, лицензии, клиентского entrypoint и отсутствие классов тестового мода. Для 1.21.x проверено преобразование имён Mixin-вставок в intermediary в выпускаемом JAR.

## Границы проверки

Публичные серверы и сторонние серверные плагины не проверялись. На локальном vanilla-сервере 1.21.10 проверены реальные подключения пяти offline-профилей, fallback по никам, цвета в табе и чате, переключение приседа через бинд и отправка 52 через бинд. Напоминание вызвано штатным предпросмотром; ожидание фактической минуты :52 не использовалось.

Тестовые запуски использовали выбранные игровые ассеты: шрифты, интерфейс, встроенные пакеты и перезвон. Остальные звуки и музыка не загружались, поэтому в логах есть предупреждения о недостающих ассетах. Эти ограничения относятся к среде разработки; мод не заменяет игровые ассеты и использует штатный звук Minecraft.

Итоговые сборки создавались Gradle 9.8.0 и JDK 25 с целевым байткодом Java 21 для 1.21.x и Java 25 для 26.x. Ранее клиент 1.21.10 также запускался на JDK 21. Для устранения ложного результата проверки прав Windows в изолированной среде применялось локальное исправление ZipFS инструментов сборки. Оно не включено в исходники мода, JAR или зависимости и не требуется в обычной среде Java с рабочими правами на кэш Gradle.

Обновление 1.0.1: добавлены G/H по умолчанию и переключатель приоритета сервер/клиент. Новый тест проверяет замену серверных цветов во всех трёх местах, сохранение жирного начертания и оформления префикса/суффикса. Тест запуска проверяет назначенные бинды на новом профиле и открывает страницу приоритета цвета.



Обновление 1.0.2: вместо демонстрационных карточек используются настоящие кадры мира на локальном сервере, с полным списком пяти участников в табе и отдельной фотографией чата. Галерея масштабируется по высоте окна. Контрольные тесты проверяют наличие четырёх PNG в каждой сборке.
