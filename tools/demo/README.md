# Источник скриншотов

Снимки сделаны в настоящем клиенте 1.21.10 при соединении с vanilla-сервером `127.0.0.1:25575`. Пять клиентов Mineflayer подключены с тестовыми именами участников. Профили offline, поэтому одновременно проверяется fallback окраски по нику. Это тестовые клиенты, а не реальные владельцы аккаунтов.

Сервер, клиенты и тестовый мод не входят в выпускаемые JAR. Во время снимков не дорисовывались имена, чат, мир или уведомления. Переключение приседа и отправка 52 вызываются через зарегистрированные бинды мода. Напоминание вызывается штатным предпросмотром. Сохранены исходные кадры 1280×720; превью таба увеличивает центральный фрагмент кадра, сохраняя все пять имён.

Для повторения нужны JDK 25, Node.js 24 и официальный vanilla server.jar 1.21.10. Поместите JAR в отдельную рабочую папку, скопируйте туда server.properties, ознакомьтесь и согласитесь с EULA Minecraft, затем запустите `java -Xmx1G -jar server.jar nogui`. Адрес в настройках ограничен localhost.

В этой папке выполните `npm ci`, затем `node controlled.cjs`. После пяти сообщений READY запустите из корня проекта:

```powershell
.\gradlew.bat runClient -Psmoke=true -PserverCapture=true
```

Клиент самостоятельно подключается, ждёт дневного света, проверяет присутствие всех пяти имён, сохраняет кадры таба, чата и уведомлений, затем закрывается. Во время съёмки окно скрыто, чтобы не перехватывать ввод. Файлы появляются в `run/smoke-<версия-мода>-1.21.10/screenshots/server-*.png`.

Чтобы завершить тестовые клиенты, запишите в commands.json `{"stop":true}`. Сервер завершается командой `stop` в его консоли.
