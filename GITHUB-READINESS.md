# Готовность к публикации 1.1.2

Репозиторий: https://github.com/Lxrits/robloxgang-utilities

Версия читается из gradle.properties. Матрица семи поддерживаемых версий — versions.json.

- CI собирает и тестирует каждый вариант; тег v1.1.2 запускает создание черновика релиза.
- Валидатор проверяет метаданные, целевой Java-байткод, десять настоящих скриншотов 1280×720, видео, звук, шрифт и лицензии.
- В релиз не попадают игровые классы и вспомогательные модули Smoke/ServerCapture/UpdateCapture.
- Результаты локальных проверок и ограничения описаны в VERIFICATION.md.
- Медиа и их источники перечислены в MEDIA-LICENSES.md. Лицензия исходного кода — MIT.

Порядок выпуска: PUBLISH.md. Черновик GitHub Release нужно опубликовать вручную после проверки.
