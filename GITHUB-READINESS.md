# Готовность к публикации

Подготовлено 13 ноября 2026 года для версии 1.0.2.

## Включено

- README с реальными игровыми снимками, зависимостями и установкой.
- MIT LICENSE, CHANGELOG, CONTRIBUTING, руководство PUBLISH.
- Шаблоны Issues и PR.
- CI с матрицей из versions.json и закреплёнными SHA GitHub Actions.
- Отдельный workflow черновика релиза: проверка тега, повторная сборка, семь JAR и SHA256SUMS.
- Скрипты PowerShell 7 для Windows/Linux; версия мода читается из gradle.properties.
- Проверка состава JAR, целевого байткода и четырёх PNG 1280×720.

## Что проверено локально

- actionlint 1.7.12: оба workflow прошли проверку без ошибок.
- Все PowerShell-файлы прошли синтаксический разбор.
- Для всех семи версий построены планы вызова Gradle; неизвестная версия отклоняется до сборки.
- Семь готовых JAR версии 1.0.2 прошли новый валидатор; сформированы SHA256SUMS.
- Валидатор отклонил отдельную тестовую копию JAR с удалённым chat.png.
- Все 27 файлов src/main (код и ресурсы) побайтово совпадают с исходным проектом 1.0.2. Функциональный код мода не менялся.
- Относительные Markdown-ссылки и пути к снимкам проверены; в исходниках не найдены локальные пути пользователя и распространённые форматы приватных ключей/GitHub-токенов.

Предыдущие девять unit-тестов и игровые прогоны для каждой Minecraft-версии описаны в VERIFICATION.md. Они не повторялись ради изменений документации и CI.

## Что остаётся после загрузки

GitHub hosted CI ещё не запускался: исходники подготовлены локально, внешний репозиторий не создан. После первого push дождитесь зелёного workflow Build and test, затем используйте процедуру выпуска из PUBLISH.md. Учётная запись автора коммита и URL origin задаются владельцем репозитория; вымышленные данные не добавлены.

Источники настройки workflow: [GitHub reusable workflows](https://docs.github.com/en/actions/how-tos/reuse-automations/reuse-workflows), [Gradle setup action](https://github.com/gradle/actions/blob/main/docs/setup-gradle.md), [gh release create](https://cli.github.com/manual/gh_release_create). Версии Actions проверены по официальным GitHub API и закреплены конкретными SHA в workflow-файлах.
