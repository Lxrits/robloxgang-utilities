# RobloxGang Utilities

Клиентский Fabric-мод для Minecraft Java Edition. На сервер устанавливать не нужно.

## Установка

1. Установите Fabric Loader для своей версии Minecraft.
2. Поместите **один** JAR RobloxGang Utilities с точным номером вашей версии в папку `mods` нужного экземпляра игры.
3. Добавьте [Fabric API](https://modrinth.com/mod/fabric-api) для той же версии Minecraft.
4. Добавьте [Mod Menu](https://modrinth.com/mod/modmenu), чтобы открыть настройки: **Mods → RobloxGang Utilities → кнопка настроек**.

Cloth Config и другие библиотеки интерфейса не нужны. Mod Menu необязателен для работы функций, но нужен для графического меню настроек.

| Minecraft | Java | Fabric API | Mod Menu |
|---|---|---|---|
| 1.21.10 | 21+ | 0.138.4+1.21.10 | 16.0.1 |
| 1.21.11 | 21+ | 0.141.6+1.21.11 | 17.0.1 |
| 26.1 / 26.1.1 / 26.1.2 | 25+ | 0.155.3+26.1.2 | 18.0.2 |
| 26.2 | 25+ | 0.161.0+26.2 | 20.0.3 |
| 26.3 | 25+ | 0.166.0+26.3 | 21.0.0 |

Для 1.21.x проверяется Loader 0.18.4, для 26.x — 0.20.1. Диапазон включает стабильные релизы, доступные на 11 ноября 2026 года. Поддержка будущих обновлений требует отдельной проверки.

## Клавиши и функции

Откройте **Настройки → Управление → Назначение клавиш → RobloxGang Utilities**. По умолчанию **G** переключает режим приседа, **H** отправляет `52`. Обе клавиши можно переназначить. Сохранённые назначения из старой версии не перезаписываются: чтобы применить новые значения, нажмите «Сбросить» у нужного действия в управлении Minecraft.

- **Переключить режим приседа** меняет штатную настройку Hold / Toggle и сохраняет её. При смене режима сбрасывается залипшее состояние приседа. Результат показывается анимированной карточкой справа сверху.
- **Написать 52 в чат** отправляет `52` по нажатию, когда вы находитесь в мире и не вводите текст в другом интерфейсе. Удержание клавиши не повторяет отправку.
- **Напоминание** срабатывает в :52 каждого часа по часовому поясу компьютера, пока открыт мир. Оно содержит текущий бинд и сопровождается коротким перезвоном. При запуске или входе в мир в пределах минуты :52 напоминание также срабатывает; переподключение в ту же минуту не повторяет его. История срабатываний хранится в пределах одного запуска игры.
- **Цвета участников** применяются к табу, чату и неймтэгам. UUID имеет приоритет. Для пиратских серверов включён fallback по актуальному нику; сравнение без учёта регистра.

## Ники и серверные цвета

При запуске мод запрашивает устаревшие ники по пяти указанным UUID у официального `sessionserver.mojang.com`. Кэш обновляется раз в 24 часа; кнопка в настройках запускает принудительное обновление. Запросы выполняются в фоне с ограниченным временем ожидания. При ошибке остаётся предыдущий кэш; до первого успешного запроса используются исходные имена. После успешного обновления старые имена перестают использоваться.

Запрос отправляет Mojang только UUID запрашиваемого профиля. Содержимое чата, адрес сервера и данные вашего аккаунта мод не отправляет.

В настройках RobloxGang выбирается **«Приоритет цвета: Сервер / Клиент»**. По умолчанию приоритет у сервера: его цвет имени, в том числе явно белый и унаследованный от родительского компонента, сохраняется. При приоритете клиента цвет участника заменяет серверный цвет только в имени, в табе, чате и неймтэге. Префиксы, суффиксы и содержимое сообщения сохраняют оформление. Цвет префикса не мешает окрашиванию отдельно оформленного имени. Мод не меняет серверные scoreboard-команды.

Обычный чат обрабатывается по профилю отправителя без изменения подписанного текста сообщения. Для системного чата серверных плагинов поддерживаются узнаваемые формы `<ник> сообщение`, `ник: сообщение`, `ник » сообщение`, включая до трёх префиксов `[роль]`; отправитель должен присутствовать в списке игроков. Произвольные нестандартные форматы и неймтэги, заменённые сервером на сущности/текстовые дисплеи, не гарантируются. Упоминания внутри сообщения не перекрашиваются.

## Настройки

В Mod Menu доступны включение функций, уведомлений и звука, громкость, длительность, масштаб, отступ, уменьшение анимации, отдельные переключатели для таба/чата/неймтэгов, fallback, включение каждого участника и HEX-цвета. Изменения применяются кнопкой **Сохранить**; **Отмена** отбрасывает изменения мода. Назначения клавиш сохраняются самим Minecraft отдельно.

Кнопка **Демо** работает и на маленьком окне. В мод встроены четыре настоящих скриншота 1280×720 из мира на локальном vanilla-сервере: таб, чат, уведомление о приседе и напоминание о 52. В табе одновременно показаны все пять участников: IlyaRobloxPro52, Lxrits, AndreyRobloxFan, TimuRobloxLOL52 и VladRobloxSHACAL. Для читаемости превью таба увеличивает центральную область исходного кадра без обрезки ников. В галерее окраски есть переключатель «Таб / Чат». На сервере использовались пять автоматизированных тестовых клиентов с этими именами; это демонстрационные профили, а не участие реальных владельцев аккаунтов. Напоминание вызвано штатным тестом уведомления. Оригинальные кадры сохранены без дорисовки интерфейса. Кнопки теста уведомлений работают без входа в мир.

Файлы: `config/robloxgang-utilities.json` — настройки, `config/robloxgang-names.json` — кэш ников. Интерфейс настроек на русском; названия действий управления имеют русскую и английскую локализации.

## Сборка исходников

Установите JDK 25 и PowerShell 7, задайте `JAVA_HOME`. Gradle Wrapper включён.

```powershell
.\build-all.ps1
# Только одна версия:
.\build-all.ps1 -MinecraftVersion 1.21.10
```

Результаты появятся в `dist/<версия-мода>/`. Java-код общего ядра хранится в `src/main/java`; задачи `adapt12111` и `modernSources` создают варианты с переименованными API. JAR для 1.21.x ремапятся Loom, сборки 26.x используют необфусцированные имена. Каждая сборка требует точного совпадения версии Minecraft.

`src/smoke` — отдельный тестовый мод для запуска клиента. Он не попадает в релизный JAR. Запуск для 1.21.10: `gradlew runClient -Psmoke=true`. Он проверяет сброс Toggle-приседа, загрузку Mixin, открытие настроек и демонстраций, после чего закрывает клиент. Для 26.x добавьте свойства из `versions.json` и `-Pmodern=true`. `-Pcapture=true` под 1.21.10 дополнительно сохраняет демонстрационные снимки.

Результаты проверок и их ограничения описаны в `../VERIFICATION.md`.
